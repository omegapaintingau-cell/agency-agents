# 📑 [RFS] 트립와이어 상품 요구사항 명세서: 레주메/포트폴리오 템플릿 패키지
**상품명:** 합격률 높이는 이직 전문 포트폴리오 & 레주메 템플릿 10종 패키지 (가칭)
**목표:** 최소한의 자원 투입으로 최대 전환율을 달성하는 트립와이어 상품 판매 시스템 구축.

## 🎯 섹션 1: 고객 여정 시나리오 (User Journey Mapping)

| 단계 | 사용자 행동 (Action) | 감정 상태 (Emotion) | 웹페이지/접점 (Touchpoint) | 핵심 전략 목표 (Goal) |
| :--- | :--- | :--- | :--- | :--- |
| **A. 유입 (Awareness)** | 문제 인식: "나의 경력은 좋은데, 왜 면접에서 떨어질까?" | 불안감, 답답함 (Pain Point) | 유튜브 영상/인스타 릴스 → 랜딩 페이지 진입 | **공감 및 자극:** 사용자의 가장 큰 고통 지점을 정확히 건드려 '해결책'을 필요하게 만듦. |
| **B. 고려 (Consideration)** | 해결책 탐색: "템플릿이 답인가? 정말 효과가 있을까?" | 기대감, 회의적 관찰 (Curiosity) | 랜딩 페이지 메인 콘텐츠 (USP 설명, 성공 사례 제시) | **신뢰 구축:** 단순 상품 판매가 아닌 '성공 로드맵'을 제공하며 전문가로서의 권위를 확립. |
| **C. 구매 결정 (Decision)** | 구매 검토: "이 가격에 이 정도 퀄리티면 괜찮을까?" | 망설임, 합리적 기대 (Hesitation) | 결제 전 최종 페이지 → CTA 버튼 클릭 | **긴급성/희소성 부여:** '지금 사야 하는 이유'를 제시하여 즉각적인 행동 유발. |
| **D. 구매 완료 (Action)** | 결제 및 다운로드: "좋아, 일단 구매해 보자." | 안도감, 만족감 (Relief) | 결제 페이지 → 감사 페이지(Thank You Page) | **확장/만족 극대화:** 트립와이어의 역할을 다하고, 다음 단계(핵심 서비스)로 자연스럽게 유도. |

## 🎨 섹션 2: 필수 콘텐츠 요소 목록 (Essential Content Elements Checklist)

단순히 템플릿 파일만 제공하는 것이 아니라, 사용자가 **'구매 후 무엇을 얻어 갈지'**에 초점을 맞춰야 합니다.

| 구분 | 상세 항목명 | 역할 및 목적 | 개발/준비 필요 자원 |
| :--- | :--- | :--- | :--- |
| **① 판매 페이지 (Landing Page)** | - 히어로 섹션 (Hook) | 사용자의 고통(Pain Point)을 명확히 정의하고, 상품이 그 해결책임을 선언. | 카피라이팅, 비주얼 디자인 |
| | - USP 및 상세 설명 | 템플릿의 기능적 우위(예: ATS 최적화, 산업별 맞춤 설계)를 구체적으로 나열. | 전문성 있는 콘텐츠 작성 (경력 분석가 관점) |
| | - 사회적 증거 (Social Proof) | *필수:* 실제 구매자 리뷰/후기 3~5개와 성공 사례(Before/After). | 가짜 후기 방지: 초기에는 '사용 예시' 위주로 대체 가능. |
| **② 상품 패키지 (The Product)** | - 10종 템플릿 파일 | 레주메, 포트폴리오 등 유형별 구분 명확화. (Word/Google Docs 호환 필수) | 디자인 자산 (Canva, Figma 등으로 제작 후 다운로드 링크 제공) |
| | - **사용 가이드 워크북 (NEW!)** | 템플릿을 *어떻게* 채워야 하는지(콘텐츠 로직), 각 항목의 의미를 설명하는 PDF. (**가장 중요**) | 콘텐츠 작성 및 디자인 |
| **③ 결제/후속 페이지** | - FAQ 섹션 | 가격, 사용 범위, 환불 정책 등 구매자가 가질 수 있는 모든 의문을 선제적으로 제거. | 법률 검토 기반의 명확한 문구 준비 |
| | - 감사 페이지 (Thank You Page) | 다운로드 링크 제공 + **핵심 Upsell 상품(메인 서비스)**에 대한 강력한 CTA 노출. | 웹 개발, 마케팅 카피라이팅 |

## 💰 섹션 3: 결제 과정 단계별 CTA 문구 및 로직 (CTA & Funnel Logic)

| 단계 | 액션 (User Action) | CTA 문구 (Copywriting Focus) | 논리/로직 (Logic Flow) |
| :--- | :--- | :--- | :--- |
| **① 랜딩 페이지 하단** | 구매 버튼 클릭 직전 | "더 이상 헤매지 마세요. 10분 안에 합격률을 높이는 시스템을 지금 경험하세요." (**Benefit 강조**) | 결제 페이지로 이동 (최소한의 정보만 요구) |
| **② 결제 완료 시점** | '결제하기' 버튼 클릭 직후 | *(None)*: 간결하고 확실하게 처리. (버튼 텍스트는 "구매 및 다운로드") | 성공적인 거래 기록 후, **즉시 감사 페이지로 리디렉션**. |
| **③ 감사 페이지 (Thank You)** | 페이지 로딩 완료 시점 | **[긴급성/희소성]** "잠깐! 아직 끝이 아닙니다. 합격률 30%를 더 높이는 [핵심 상품 이름]을 단 5분간 할인된 가격으로 추가 구매할 기회입니다." (**Upsell 유도**) | 다운로드 링크 제공 $\rightarrow$ **타이머 카운트다운 + 메인 상품 Upsell CTA** 노출. (자동 이탈 방지) |

## 🧪 섹션 4: 성공적인 구매 전환을 위한 A/B 테스트 가설 3가지 (A/B Testing Hypotheses)

가장 효과적인 구매 유도 요소를 발견하기 위해, 다음 세 가지 가설에 기반한 A/B 테스트를 진행해야 합니다.

**1. 헤드라인(Headline) A/B 테스트: 고통 vs. 이익 강조**
*   **Hypothesis:** 사용자의 '고통점'을 직격하는 문구(Pain Point Focus)가 단순 '이익 제시'(Benefit Focus)보다 초기 전환율에 더 높다.
*   **Test A (Pain):** "면접마다 탈락하는 당신의 레주메, 이 3가지 문제로 인해 무너지고 있습니다." (문제 제기형)
*   **Test B (Benefit):** "ATS 통과 및 면접관 시선을 사로잡는 합격률 최적화 포트폴리오 패키지." (해결책 제시형)

**2. CTA 버튼 문구 A/B 테스트: 지연 vs. 즉각성 강조**
*   **Hypothesis:** '행동 유발'에 초점을 맞춘 긴박한 문구가 단순히 제품의 기능을 나열하는 것보다 클릭률(CTR)이 높다.
*   **Test A (지연):** "패키지 상세 보기" / "구매 방법 알아보기"
*   **Test B (즉각성):** "합격 로드맵 다운로드 받기" / "지금 바로 합격 레주메 얻기"

**3. 상품 가격 제시 방식 A/B 테스트: 가치 vs. 할인율 강조**
*   **Hypothesis:** 단일 할인가(Discount)를 명시하는 것보다, **'절약되는 시간과 비용'**이라는 관점에서 가치를 계산하여 보여주는 것이 구매 심리를 더 자극한다.
*   **Test A (할인):** "정가 19만원 $\rightarrow$ $49,000 \text{원}$"
*   **Test B (가치):** "이 패키지를 사용하면 평균 5시간의 재작업 시간을 절약하고, 최소 면접 기회 2회를 확보할 수 있습니다."
