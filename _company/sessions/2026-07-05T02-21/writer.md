# ✨ Module 1: 경험 포장 마스터 (Experience to KPI System)
**[모듈 목표]**: 막연한 '경력 나열'을 넘어, **측정 가능한 성과 지표(KPI)**로 구조화하여 이직 시장에서 가장 매력적인 스토리텔링 자산으로 재탄생시킨다.

---

## 📚 학습 가이드: 왜 기존 방식으로는 안 될까? (The Pain Point)
대부분의 사람들은 경력을 '시간 순서'대로 나열합니다. 하지만 기업이 원하는 것은 **'문제 해결 능력'**입니다.

*   ❌ **(X)** "저는 지난 3년간 마케팅 업무를 했습니다." (추상적, 측정 불가)
*   ✅ **(O)** "A 문제 상황을 발견하고, B 시스템을 도입하여 C 성과를 달성했습니다." (구체적, 수치화됨)

이 모듈은 당신의 경력을 단순한 '이력'이 아닌, 기업이 즉시 활용할 수 있는 **‘성과 보고서’**로 전환하는 프로세스를 제공합니다.

---

## 🛠️ 워크북 액션 플랜: 5단계 KPI 추출 체크리스트
아래 5단계를 순서대로 따라 하며 빈칸을 채우세요. 모든 아웃풋물은 최종적으로 레주메의 '성과 요약' 섹션을 구성하게 됩니다.

### Step 1. 핵심 성과 발견 (The Discovery) - [시간: 30분]
가장 자랑스럽지만, 말이 잘 안 나오는 프로젝트를 하나만 선택하세요.
*   **🔑 질문:** 이 경험에서 내가 *가장 큰 변화*를 만들거나, *남들이 놓친 문제*를 해결했던 순간은 언제인가요?
*   **💡 액션 플랜:** 당시의 상황과 당신이 취한 행동을 메모합니다. (STAR 기법의 S와 T만 채우세요.)

| 항목 | 나의 경험 기록 (Draft) | 목표 KPI 전환 질문 |
| :--- | :--- | :--- |
| **Situation (S)**: 배경 및 문제 정의 | *예: 기존 고객 문의 대응 시스템이 수작업이라 오류가 잦고 시간이 오래 걸림.* | 이 문제를 해결하지 못했을 때, 조직에 발생했던 '구체적 손실'은 무엇이었나요? (비용/시간/기회) |
| **Task (T)**: 나의 역할 및 목표 | *예: 문의 대응 시간을 줄이고 오류율을 낮추는 것이 목표였음.* | 이 문제를 해결하기 위해, 내가 가진 자원(돈, 사람, 시간) 중 가장 부족했던 것은 무엇이었나요? |

### Step 2. 액션 구조화 (The Action Mapping) - [시간: 45분]
당신의 행동을 단순한 '노력'이 아닌 **'체계적 시스템 적용 과정'**으로 재구성합니다.
*   **🔑 질문:** 단순히 열심히 한 게 아니라, *어떤 방법론(Framework)* 을 도입했나요? (예: A/B 테스트 설계, 데이터 수집 주기 변경, 3단계 프로세스 구축 등)
*   **💡 액션 플랜:** 당신이 실제로 수행한 구체적인 '행동'을 나열합니다. 이때 사용하는 **도구/방법론의 이름**을 반드시 명시하세요.

**[필수 아웃풋물]: 문제 해결 과정 3단계 로직 (Flowchart Draft)**
1.  (진단) $\rightarrow$ 2. (실험/개선) $\rightarrow$ 3. (최종 적용/확산)
*   *예시:* **[Before]** - 문의 접수 (메일함 쌓임) $\rightarrow$ **[Action]** - 전용 폼(Typeform) 도입 및 답변 자동화 로직 설계 $\rightarrow$ **[After]** - 실시간 응답률 80% 달성

### Step 3. 결과 수치화 (The Quantification) - [시간: 20분]
가장 중요한 단계입니다. 당신의 행동이 가져온 결과를 숫자로 말하세요.
*   **🔑 질문:** 그 '성과'를 **퍼센트(%)**, **금액(원)**, 또는 **개수(N)** 로 나타낼 수 있나요?
*   **💡 액션 플랜:** 반드시 비교가 가능한 Before/After 데이터를 찾으세요.

| 항목 | Before (문제) | After (해결책 적용 후) | 개선율 (%) | 성과 지표 (KPI) |
| :--- | :--- | :--- | :--- | :--- |
| **예시:** 고객 문의 대응 시간 | 평균 48시간 소요 | 시스템 도입 후 6시간으로 단축 | 87.5% 감소 | 응대 속도 개선 지표 |
| **나의 경험 1** | | | | |
| **나의 경험 2** | | | | |

### Step 4. 스토리라인 구축 (The Narrative Reframing) - [시간: 30분]
수치화된 성과를 이직 면접관이나 채용 담당자가 흥미롭게 들을 수 있는 '스토리'로 재구성합니다.
*   **🔑 가이드:** 문제 제기 $\rightarrow$ 나의 역할 강조 (주체성) $\rightarrow$ 해결책 제시(시스템) $\rightarrow$ 측정 가능한 성과 발표의 순서를 지킵니다.

**[필수 아웃풋물]: 3줄 요약 스크립트 초안**
1.  **(Problem/Context):** [이직 시장에서 가장 매력적인 문제 상황]을 포착했습니다. (청중 공감 유도)
2.  **(My Action):** 저는 기존의 방식 대신, \[새로운 체계적 시스템명]을 설계하고 적용하여... (나의 독창성 강조)
3.  **(Impact/Result):** 그 결과, 회사에 **\[수치화된 KPI]** 만큼의 성과를 창출했습니다. (결론 및 임팩트 제시)

### Step 5. 최종 검토 및 최적화 (The Polishing) - [시간: 15분]
최종적으로 작성된 내용을 '채용 담당자' 입장에서 냉정하게 검토합니다.
*   **✔️ 체크리스트:**
    *   [ ] 모든 경험 서술에 **"주어(나)"의 역할이 명확한가?** (남들이 했다는 뉘앙스 제거)
    *   [ ] '노력' 대신 **'시스템/방법론'을 키워드로 사용했는가?** (사고 과정 강조)
    *   [ ] 모든 성과에 최소 한 가지 이상의 **KPI(%)나 숫자**를 붙였는가? (추상성 제거)
